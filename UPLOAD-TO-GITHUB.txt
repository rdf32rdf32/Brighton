ALBION FAN HUB r75 — GITHUB PAGES UPLOAD

1. Open the Brighton repository on GitHub.
2. Upload every file and folder contained in Brighton-Fan-Hub-r75-FULL.zip to the repository root.
3. Replace files when GitHub asks.
4. Keep the .github/workflows and tools folders: they provide automatic validation.
5. Commit the changes and allow GitHub Pages to redeploy.

Runtime filenames such as app-r66.js, albion-data-r66.js and shootout-r66.js are intentionally retained so the current deployed files are replaced cleanly. index.html uses r75 cache-busting query strings.

The smaller Brighton-Fan-Hub-r75-CHANGED.zip contains only files changed from r74. The FULL zip is the safest upload.

If old release-note files are already in the repository, they can remain or be deleted; they are not used by the live site.
